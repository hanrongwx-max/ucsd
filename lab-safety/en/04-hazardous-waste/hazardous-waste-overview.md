# Hazardous Waste

## Overview

Before handling waste, first determine what it is. Understanding the waste's characteristics and composition matters most when handling and disposing of hazardous waste.

EH&S manages all laboratory, research, and medical waste — chemical, biological, and radioactive — and general hazardous waste across the university, aiming for timely, environmentally appropriate disposal and recycling.

## How to Identify Hazardous Waste

Follow "How to Identify Hazardous Chemical Waste": https://blink.ucsd.edu/safety/research-lab/hazardous-waste/identify.html

## How to Use Hazardous Waste Tags

- Generators of chemical and radioactive hazardous waste must apply for and receive a **Waste Generator Number (WGN)** before EH&S can collect their waste.
- Generate tags with the **Online Waste Tag Program (OTP)**: https://ehs.ucsd.edu/pip/do/DisplayWasteTagForm
- Related: How to Request a Hazardous Waste Collection; Non-Hazardous Waste Collection (Facility Services); Hazardous Waste Collection Schedule.

## Waste Disposal Guidance List

Procedures for specific wastes such as batteries, paint, and pharmaceuticals.

## Storage Time Limits (at the site of generation)

| Waste Type | Maximum Time Limit |
|---|---|
| Hazardous chemical waste | 90 days |
| Mixed waste | 90 days |
| Universal waste / batteries | 240 days |
| Radioactive waste | 240 days |
| Non-hazardous waste | 240 days |
| Recyclable materials | 240 days |

For biohazardous waste, see the biohazardous disposal guidelines.

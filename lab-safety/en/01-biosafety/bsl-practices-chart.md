# Biosafety Level (BSL) Practices Chart

Research and teaching involving infectious agents requires prior IBC approval through the BUA process. Each lab is assigned a biosafety level based on materials and activities; the IBC uses CDC/NIH levels and may modify requirements. **Containment** = methods, practices, procedures, facilities, and equipment that reduce exposure.

## A. Hazard Levels

| | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| Degree of hazard | Low; well-characterized agents not known to cause disease in healthy adults | Moderate | High; agents linked to lab-acquired infections or serious/lethal outcomes | High; moderate-to-high hazard, serious or potentially lethal |
| Example | E. coli (lab strain) | Streptococcus pyogenes | Listeria monocytogenes | Mycobacterium tuberculosis |

## B. Standard Microbiological Practices

| Practice | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| Lab access | Not restricted; doors not propped open | Doors closed during BSL-2 work | Same as BSL-2 | Closed and locked |
| Signage | Biohazard sign | Biohazard symbol on room sign; large equipment labeled | same | same |
| Solid waste | Biomedical waste vendor | Vendor or autoclave with EH&S approval | Same; pathological/infected animals incinerated | Autoclave in lab |
| Liquid cultures | 10% fresh-daily bleach, 30 minutes | Bleach or autoclave with approval | Same; prion liquids into 1 N NaOH, collected as hazardous waste | Autoclave in lab |
| Eating/drinking/cosmetics/contact lenses | Only in designated clean areas | Clean areas only; not when aerosol transmissible pathogens are used | **Never** | **Never** |
| Sharps | Safe handling practices; plasticware instead of glassware when possible | | | |
| Work surfaces | Decontaminate daily, after work, after spills | | | |
| Pipetting | **Mechanical only; no mouth pipetting** | | | |
| Waste storage | Double red bags in rigid, leakproof labeled containers | | | |
| Handwashing | After handling hazardous materials and before leaving | | | |
| Training | Supervisor ensures training | | | |
| Medical surveillance | Recommended | Required, with immunizations offered | | |
| Equipment decontamination | Green-tagged by EH&S before repair, maintenance, removal | | | |
| Unrelated animals/plants | Allowed if approved | Not allowed | | |
| Glassware use | N/A | IBC recommended | IBC required for HBV, HCV, HIV | IBC required |

## D. Facilities

| | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| Ventilation | Negative pressure vs. lower-level/non-lab space; single-pass air | | | |
| Handwashing sink | Required | | | Hands-free (foot, elbow, electronic) |
| Autoclave | Not required | | | Required in lab |
| Eyewash | Recommended | Required | Required | Required in lab |
| Doors | Required | Self-closing with locks | Self-closing with locks | Two self-closing doors (anteroom), palm scanners |
| Chairs | Non-porous, easily disinfected | | | |
| Surfaces | Easily cleaned; no carpets | | | Sealed seams, floors, walls, ceilings; sealable for fumigation |

## BSL-2+ Agents with IBC-approved Exposure Control Plans
Shiga toxin-producing E. coli; HBV; HCV; HIV; influenza; prions; Listeria monocytogenes; LCMV; macaque tissue; oncogenes in viral vectors; rabies; Salmonella Typhi; Shigella dysenteriae type 1; SIV; Toxoplasma gondii; vaccinia; Zika.

## Aerosol-Generating Processes
Centrifuging; grinding; blending; vigorous shaking or mixing; sonic disruption; opening containers with high internal pressure; intranasal inoculation of animals; harvesting tissues from animals or embryonated eggs.

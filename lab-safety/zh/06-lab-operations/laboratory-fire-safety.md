# 实验室消防安全检查

校园消防官与 RAP 合作，依据加州法规 Title 19、加州消防法规和校园政策检查所有校园实验室（不进行消防演练）。

| 检查项 | 检查内容 / 要求 |
|---|---|
| 生物安全柜 | 除经 EH&S 和系主任批准外，BSC 内禁止明火和易燃气体；拆除燃气管；新 BSC 不接燃气 |
| 消防规范化学品限量 | 库存按控制区不超过 MAQ（部门安全官可在 My Research Safety 中监控） |
| 化学品储存 | 不相容物隔离并标识；自燃物只能在全喷淋建筑中 |
| 压缩气体 | 有经批准的 HCP；气瓶始终固定 |
| 天花板和墙体 | 保持完整；任何穿墙开孔须经设施部门和消防与生命安全部门批准 |
| 走廊 | 无障碍物；出口标志和应急照明正常；防火门不得撑开 |
| 用电 | 不得有磨损电线、过载插座、串联插排、延长线、裸露接线盒、被遮挡/无标识的配电箱 |
| 出口 | "出口门保持关闭、无遮挡、可正常使用"；出口标志可见且亮着 |
| 灭火器 | 任何方向行走 **75 英尺**内有 ABC 灭火器，实验室内至少一具；最低等级 **4A:60B:C**；特种灭火器（CO2、D 类）是补充而非替代；**每月**检查。"干粉（Dry Chemical）"灭 A/B/C 类火；"干粉剂（Dry Powder）"灭 D 类（金属）火 |
| 易燃液体 | 不超限量；使用经批准的防爆冰箱 |
| 障碍物 | 频闪灯、报警器、配电箱、喷淋头、出口均保持畅通 |
| PPE | 任何时候的最低着装：**长裤和包头包跟的鞋**；其他按危害评估/HCP |
| 喷淋头 | 喷淋头下方至少保留 **18 英寸（约 46 cm）**净空；无喷淋建筑不得有自燃物 |

教训：一次校园实验室火灾中，离火源最近的喷淋头因被遮挡未启动；火势蔓延，三个喷淋头启动，水一直淹到地下室。

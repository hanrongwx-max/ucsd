# 下水道排放：哪些东西可以倒入下水道？

"倒进下水道的东西最终都会流入大海。"圣地亚哥都市污水处理部门对下水道排放有严格规定。

## 可以倒入下水道的条件

物质必须**同时满足**以下所有条件：

1. **无危险性** —— 不含放射性废物；不含危险化学废物；不含未经处理的生物危害废物。
2. **液体** —— 不是固体、污泥或黏稠物质。
3. **不干扰污水处理** —— 无腐蚀性 pH；无油脂；无超过 10 加仑的高温液体（≥150 °F，约 66 °C）。

不确定时联系 EH&S 环境管理设施：hazwaste@ucsd.edu 或 (858) 534-3660。

保护下水口免受化学品溢洒；不得用水槽储存化学品或作为二次容器。"通过水槽、故意蒸发或作为普通垃圾处置危险废物是违法的。"

## 按物质分类

| 物质 | 能否倒入下水道？ |
|---|---|
| 生物危害固体 | 不可以 |
| 生物危害液体 | 须先灭活：漂白剂与液体废物 1:9 作用 30 分钟，或高压灭菌（不加漂白剂） |
| 管制物质 | 不可以 |
| 放射性废物 | 不可以 |
| 危险化学废物 | 不可以 |
| 固体、污泥、黏稠物 | 不可以 |
| 粉末和盐 | 不可以 —— **不得溶于水后倒掉** |
| pH 2.0–5.0 的腐蚀性废物 | 须调节至 5.0 以上、12.5 以下才可以；否则按危险废物 |
| pH ≤ 2.0 或 ≥ 12.5 的腐蚀性废物 | 绝不可以 —— 一律按危险化学废物；**不得自行调节** |
| ≥150 °F 的非危险热液体 | 10 加仑及以上不可以（须先冷却） |
| 油脂 | ≥ 500 mg/L 不可以。机油/齿轮油和机械润滑脂 → 危险废物；植物油、猪油、起酥油 → 普通垃圾 |
| 醇类 | 仅限无危险浓度；乙醇低于 24% 无危险。**禁止稀释后排放** |
| 溴化乙锭 | 任何浓度都不可以（按危险废物） |
| 福尔马林 / 甲醛 | 甲醛 < 2.9% 且不含甲醇或其他危险化学品可以；禁止稀释 |
| 过氧化氢 | 仅限 < 8%；禁止稀释 |
| 照相 / X 光冲洗药液 | 仅限未与定影液混合的废显影液 |
| 其他化学品 | 仅限无危险浓度；禁止稀释 |
| 乳胶漆、油漆 | 不可以 |
| 清洗和冲洗水 | 被危险物质或强碱、强酸、有毒清洗液污染的不可以 |

漂白剂是全校唯一批准的化学消毒剂。如需替代消毒剂，发邮件至 EHSBIO@UCSD.EDU 说明材料、化学品、浓度、接触时间和处置方式（5 个工作日内回复）。

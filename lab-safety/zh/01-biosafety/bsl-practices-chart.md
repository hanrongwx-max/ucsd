# 生物安全等级（BSL）操作规范对照表

涉及感染性因子的科研和教学须事先通过 BUA 流程获得 IBC 批准。每个实验室根据材料和活动风险被分配一个生物安全等级；IBC 采用 CDC/NIH 的等级标准，并可针对具体项目调整要求。**防护（Containment）**指降低暴露的方法、操作、程序、设施和设备。

## A. 危害等级

| | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| 危害程度 | 低；特性明确、不会导致健康成人患病的因子 | 中等 | 高；与实验室获得性感染有关或可致严重/致命后果 | 高；中至高危害，可致严重或致命后果 |
| 示例 | 大肠杆菌（实验室菌株） | 化脓性链球菌 | 单核细胞增生李斯特菌 | 结核分枝杆菌 |

## B. 标准微生物操作规范

| 规范 | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| 进入限制 | 不限制；门不得撑开 | BSL-2 操作时关门 | 同 BSL-2 | 关闭并上锁 |
| 标志 | 生物危害标志 | 房间标牌有生物危害符号；大型设备贴标 | 同左 | 同左 |
| 固体废物 | 生物医疗废物服务商 | 服务商，或经 EH&S 批准高压灭菌 | 同左；病理废物/感染动物须焚烧 | 实验室内高压灭菌 |
| 液体培养物 | 当日新配 10% 漂白剂，30 分钟 | 漂白剂或经批准高压灭菌 | 同左；朊病毒液体加入 1 N NaOH，按危险废物收集 | 实验室内高压灭菌 |
| 饮食/化妆/隐形眼镜 | 仅限指定清洁区 | 仅限清洁区；使用气溶胶传播病原体时禁止 | **禁止** | **禁止** |
| 锐器 | 制定安全操作规范；尽量用塑料器皿代替玻璃 | | | |
| 台面 | 每天、工作结束后、溢洒后去污 | | | |
| 移液 | **只能用机械移液器，禁止口吸** | | | |
| 废物储存 | 双层红袋置于有标识的硬质防漏容器中 | | | |
| 洗手 | 接触危险材料后及离开实验室前 | | | |
| 培训 | 主管确保人员受训 | | | |
| 医学监测 | 建议 | 必须，并提供相应疫苗 | | |
| 设备去污 | 维修、保养或移出前由 EH&S 挂绿色标签 | | | |
| 无关动植物 | 经批准可允许 | 不允许 | | |
| 使用玻璃器皿 | 不适用 | 建议经 IBC 批准 | HBV、HCV、HIV 须经 IBC 批准 | 须经 IBC 批准 |

## C. 安全设备

| 设备 | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| II 级生物安全柜（每年认证） | 不要求 | 所有产生气溶胶的操作 | 所有工作 | 所有工作 |
| 密封转子/安全杯 | 不要求 | 高浓度或大体积（或离心机置于认证 BSC 内） | 所有工作 | 所有工作 |
| 实验服 | 必须 | 必须 | 必须 | 前襟封闭的一次性隔离衣 |
| 手套 | 必须 | 必须 | 必须 | 必须 |
| 眼部防护 | 必须，包括在 BSC 内 | | | |
| 袖套 | 不要求 | | 建议 | 建议 |
| HEPA 过滤真空管路 | 必须 | | | |

## D. 实验室设施

| | BSL-1 | BSL-2 | BSL-2+ | BSL-3 |
|---|---|---|---|---|
| 通风 | 相对低等级/非实验区为负压；单程送风 | | | |
| 洗手池 | 必须 | | | 免手动（脚踏、肘动或感应） |
| 高压灭菌器 | 不要求 | | | 实验室内必须有 |
| 洗眼器 | 建议 | 必须 | 必须 | 实验室内必须有 |
| 门 | 必须 | 自闭并可上锁 | 自闭并可上锁 | 两道自闭门形成缓冲间，掌纹识别 |
| 椅子 | 无孔、易消毒材料 | | | |
| 表面 | 易清洁；无地毯 | | | 接缝、地面、墙、天花板密封；可密封熏蒸 |

## 需加强防护的 BSL-2+ 因子（有 IBC 批准的暴露控制计划）
产志贺毒素大肠杆菌；HBV；HCV；HIV；流感病毒；朊病毒；单核细胞增生李斯特菌；LCMV；猕猴组织；病毒载体中的癌基因；狂犬病毒；伤寒沙门菌；1 型痢疾志贺菌；SIV；刚地弓形虫；痘苗病毒；寨卡病毒。

## 产生气溶胶的操作
离心；研磨；搅拌；剧烈振荡或混合；超声破碎；打开内部高压的容器；动物滴鼻接种；从动物或鸡胚中采集组织。
